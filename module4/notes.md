Lesson 4.1: Version Control
    Version Control System (VCS) gives you 3 things that change how you work:
    A complete history of every change ever made to every file in your project. You can go back at any point in time
    The ability to work on multiple ideas at the same time using branches, without breaking the working version of your code
    A way to collaborate with other developers by sharing and merging changes without overwriting each other’s work
Git vs. GitHub - What is the difference?
    Git is the version control system
    GitHub is the website that hosts your Git repositories and adds collaboration tools on top
